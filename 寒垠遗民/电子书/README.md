# 寒垠遗民

**作者：jwk000**

> 又名《我从未见过海》 未来 · 星际难民 · 生态科幻 · 第一人称

***

## 内容简介

灰星，编号 KN-8813-e。

它离自己的恒星太远。一年二十个月，只有第七个月是雨季：冰雪化开，矮麦在三十天里长完一生。剩下的十九个月，气温在零下四十到零下八十度之间。地面上没有海，没有树，没有大的活物。活的东西都在地下，都很小。

这颗星球上的人，是八百年里三批被送来的：流放犯、逃亡者、和遗落的人。他们在这里活了下来，也在这里打了八百年的仗——不为别的，为水。

沈砾是工兵班的一个兵。他二十二岁那年，雨季照常来了。他没见过海，只在梦里见过。他把那个梦藏了一辈子，也把那个梦带上了船。

***

## 关于这本书

* **体量**：五卷 · 五十一章 · 纯汉字约 9.7 万
* **结构**：卷一《灰》· 卷二《湮》· 卷三《渡》· 卷四《新岸》· 卷五《归》
* **视角**：第一人称（沈砾）

书里有一条规矩：在卷一至卷三里，「海」这个字几乎不出现。它只以梦和一首歌的形式活着——那首歌没有名字，只有四句词：

> 蓝的，咸的，一直响的，\
> 一直响的，回头又回过头，\
> 我在岸上等你，你在岸上等我，\
> 我们谁也没到过岸上。
