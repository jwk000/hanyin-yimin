# 电子书构建说明

这个文件夹就是一本 GitBook。整个书稿从 `..\正文\` 自动转换而来，正文改动之后重新跑一次脚本即可同步。

## 文件夹里都是什么

| 文件 | 作用 |
|---|---|
| `README.md` | 书名页（GitBook 的首页） |
| `SUMMARY.md` | 目录，GitBook 靠它组织全书 |
| `卷一.md` … `卷五.md` | 五个分卷页 |
| `正文/ch01.md` … `ch51.md` | 五十一章，每章一页 |
| `book.json` | 书名、作者、语言、字体等设置 |
| `.bookignore` | 不发布到网上的文件 |
| `生成电子书.ps1` | 从 `..\正文\` 重新生成本目录 |
| `生成EPUB.py` | 打包 EPUB，并生成打印版 HTML |
| `输出/` | 成品：EPUB、PDF、打印版 HTML、预览图 |
| `_book/` | 本地构建出来的网站（可删，能重建） |

**不要直接改 `电子书/` 里的章节文件**——它们会被脚本覆盖。要改就改 `..\正文\`，然后重新生成。

## 一、改完正文之后，重新生成

在 PowerShell 里：

```powershell
cd "D:\GameDev\ai-world\寒垠遗民\电子书"
.\生成电子书.ps1
```

## 二、本地预览网页版

```powershell
cd "D:\GameDev\ai-world\寒垠遗民\电子书"
npx honkit serve
```

然后浏览器打开 http://localhost:4000 。按 `Ctrl+C` 停止。

只想生成静态网站（输出在 `_book\`）不预览：

```powershell
npx honkit build
```

`npx honkit` 第一次运行会自动下载 HonKit（GitBook 的社区续作，用法完全一样，命令从 `gitbook` 换成 `honkit`）。

## 三、生成 EPUB 和 PDF

```powershell
cd "D:\GameDev\ai-world\寒垠遗民\电子书"
python .\生成EPUB.py
```

会得到：

- `输出\寒垠遗民.epub` —— 直接丢进 Kindle、Apple Books、多看、微信读书都能看。
- `输出\打印版.html` —— 浏览器打开后按 `Ctrl+P` 就能打印成 PDF。

想直接命令行出 PDF（用本机 Chrome）：

```powershell
$c = "C:\Program Files\Google\Chrome\Application\chrome.exe"
$h = "D:\GameDev\ai-world\寒垠遗民\电子书\输出\打印版.html"
$o = "D:\GameDev\ai-world\寒垠遗民\电子书\输出\寒垠遗民.pdf"
Start-Process $c -ArgumentList @("--headless=new","--no-pdf-header-footer","--print-to-pdf=$o",([System.Uri]::new($h).AbsoluteUri)) -Wait
```

**调整版式**：想改成 A5、换字号或行距，打开 `生成EPUB.py`，改 `PRINT_CSS` 开头那几行就行。

**想要 Calibre 那条路**：装上 Calibre 之后，`npx honkit epub` 和 `npx honkit pdf` 也能用（HonKit 的这两个命令靠 Calibre 的 `ebook-convert`）。

## 四、发布成在线 GitBook

GitBook 官方现在只支持「从 Git 仓库同步」，不能直接上传文件夹。步骤：

1. 把 `D:\GameDev\ai-world` 做成一个 Git 仓库，推到 GitHub（私有仓库也可以）。
2. 登录 [gitbook.com](https://www.gitbook.com)，新建一个 space。
3. 在 space 的设置里选 **Git Sync**，授权 GitHub，选中刚才那个仓库。
4. **根目录填 `寒垠遗民/电子书`**（这一步最关键，填错 GitBook 就找不到 `SUMMARY.md`）。
5. 之后每次 `git push`，GitBook 会自动重新构建。

如果不想用 GitBook 云端，`_book\` 这个文件夹本身就是纯静态网站，扔到任意静态托管（GitHub Pages、Netlify、Vercel、对象存储）都能直接看。
