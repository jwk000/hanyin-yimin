# 电子书构建说明

这个文件夹就是一本 GitBook。整个书稿从 `..\正文\` 自动转换而来，正文改动之后重新跑一次脚本即可同步。

## 文件夹里都是什么

| 文件 | 作用 |
|---|---|
| `README.md` | 书名页（GitBook 的首页） |
| `SUMMARY.md` | 目录，GitBook 靠它组织全书 |
| `卷一.md` … `卷五.md` | 五个分卷页 |
| `正文/ch01.md` … `ch51.md` | 五十一章，每章一页 |
| `book.json` | 书名、作者、语言、字体等设置 |
| `gitbook-docs.yaml` | GitBook 站点结构，把本目录映射成一个 space |
| `.gitbook.yaml` | 告诉 GitBook 首屏是 `README.md`、目录是 `SUMMARY.md` |
| `.bookignore` | 不发布到网上的文件 |
| `生成电子书.ps1` | 从 `..\正文\` 重新生成本目录 |
| `生成EPUB.py` | 打包 EPUB，并生成打印版 HTML |
| `输出/` | 成品：EPUB、PDF、打印版 HTML、预览图 |
| `_book/` | 本地构建出来的网站（可删，能重建） |
| `封面/` | 封面：HTML 排版稿、SVG 矢量版、PNG 成品、生成脚本 |

**不要直接改 `电子书/` 里的章节文件**——它们会被脚本覆盖。要改就改 `..\正文\`，然后重新生成。

## 一、改完正文之后，重新生成

在 PowerShell 里：

```powershell
cd "D:\GameDev\ai-world\寒垠遗民\电子书"
.\生成电子书.ps1
```

## 二、本地预览网页版

```powershell
cd "D:\GameDev\ai-world\寒垠遗民\电子书"
npx honkit serve
```

然后浏览器打开 http://localhost:4000 。按 `Ctrl+C` 停止。

只想生成静态网站（输出在 `_book\`）不预览：

```powershell
npx honkit build
```

`npx honkit` 第一次运行会自动下载 HonKit（GitBook 的社区续作，用法完全一样，命令从 `gitbook` 换成 `honkit`）。

## 三、生成 EPUB 和 PDF

```powershell
cd "D:\GameDev\ai-world\寒垠遗民\电子书"
python .\生成EPUB.py
```

会得到：

- `输出\寒垠遗民.epub` —— 直接丢进 Kindle、Apple Books、多看、微信读书都能看。
- `输出\打印版.html` —— 浏览器打开后按 `Ctrl+P` 就能打印成 PDF。

想直接命令行出 PDF（用本机 Chrome）：

```powershell
$c = "C:\Program Files\Google\Chrome\Application\chrome.exe"
$h = "D:\GameDev\ai-world\寒垠遗民\电子书\输出\打印版.html"
$o = "D:\GameDev\ai-world\寒垠遗民\电子书\输出\寒垠遗民.pdf"
Start-Process $c -ArgumentList @("--headless=new","--no-pdf-header-footer","--print-to-pdf=$o",([System.Uri]::new($h).AbsoluteUri)) -Wait
```

**调整版式**：想改成 A5、换字号或行距，打开 `生成EPUB.py`，改 `PRINT_CSS` 开头那几行就行。

**想要 Calibre 那条路**：装上 Calibre 之后，`npx honkit epub` 和 `npx honkit pdf` 也能用（HonKit 的这两个命令靠 Calibre 的 `ebook-convert`）。

## 四、发布到 GitBook 官网

GitBook 官网（gitbook.com）只能从 Git 仓库同步，不能直接上传文件夹，所以先把仓库推到 GitHub，再让 GitBook 去读这个仓库。

**仓库**：https://github.com/jwk000/hanyin-yimin （分支 `main`）

在 GitBook 里的操作：

1. 登录 [gitbook.com](https://www.gitbook.com)，新建一个 site。
2. 左栏进 **Git Sync**，点 **Connect GitHub** 授权。
   *如果仓库列表里找不到，说明 GitHub 上 [GitBook 应用](https://github.com/apps/gitbook-com) 的授权范围没包含这个仓库，去 GitHub 的 Settings → Applications 里补上。*
3. **Source repository** 选 `jwk000/hanyin-yimin`，分支选 `main`。
4. 初始同步方向选 **Swap direction**——让仓库内容覆盖 GitBook 里那份空白内容。
5. **Project directory** 填 `寒垠遗民/电子书`。
6. **Content mapping** 把 space 指向 `./`。
7. 点 **Sync**。

同步是双向的：在 GitBook 里改的内容会提交回 GitHub，GitHub 上的提交也会同步到 GitBook。

只有 `SUMMARY.md` 里链接到的文件才会变成书页，`说明.md`、两个生成脚本不会被当成正文。

## 五、正文改完之后怎么更新线上版本

1. 改 `..\正文\` 里的章节。
2. 跑 `.\生成电子书.ps1` 同步到 `电子书\`。
3. `git add -A` → `git commit -m "改稿"` → `git push`。
4. GitBook 检测到 push 会自动重新构建。

想重出 EPUB / PDF / 网页版，见前面第一到第三节。

## 六、封面

`封面\` 目录里有三套东西：

| 文件 | 说明 |
|---|---|
| `封面-寒垠遗民.png` | 正式封面，1600×2400 |
| `封面-A.html` / `-B.html` / `-C.html` | 三个排版稿（HTML+CSS）。B 是正式封面用的那一版 |
| `封面-A.png` / `-B.png` / `-C.png` | 三个稿子的渲染结果 |
| `封面-寒垠遗民.svg` | 矢量版，文字是 `<text>`，想改字直接改这个 |
| `封面-寒垠遗民-转曲.svg` | 矢量版，文字已转成轮廓，换机器不会掉字体，给印厂或排版用这个 |
| `生成封面.ps1` | 用本机 Chrome 把三个 HTML 渲染成 PNG |
| `生成封面SVG.py` | 生成两个 SVG（需要 `fontTools`） |

改字或改版式：改 HTML 里的文字和 `top`/`font-size`，跑一次 `.\生成封面.ps1` 即可。
想改 SVG 的文字，先改 `生成封面SVG.py` 里的 `LAYOUT`，再跑 `python .\生成封面SVG.py`——两个 SVG 会一起重生成，保证一致。

另外，项目根目录的 `..\插画提示词.md` 是给绘图模型用的：封面 4 版 + 5 张卷首图 + 51 章插画，每条都有中英双语提示词。
