# 《寒垠遗民》分卷分章大纲

**作者**：jwk000
**体量**：约 97,000 字（纯汉字 97,045）· 5 卷 · 51 章 · 单章平均约 1,900 字
**视角**：第一人称（沈砾）
**说明**：本表按定稿正文重排。早期初版曾按 34 章设计，正文实际扩展为 51 章。

## 卷一 · 灰（第 1—7 章｜约 14,700 字）
**主题：水，以及为水而死的人。**
本卷只做一件事——让读者相信这颗星球，也爱上这群人。

| 章 | 标题 | 内容要点 |
|---|---|---|
| 01 | 雨季的第一天 | 第七个月第一个日头。憋了十九个月的水汽从地平线浮起来，几百人爬出地窖，仰头接雨。介绍沈砾、工兵班、钉子、灰雀、言，和头盔内壁那个别人看不见的字。夜里有三声炮响——北坳的旗插上了三号哨塔。 |
| 02 | 三十天的命 | 雨季里的活：种矮麦、修渠、洗身、埋人。聚居地的社会结构——水头、配给、以水计价的买卖。写沈砾藏着的那个梦。 |
| 03 | 闭月 | 雨季最后一天到翌日清晨，气温在四十小时内骤降六十度。写极冷。写谁没撑过去。灰雀冻掉两根手指。沈砾开始明白：这颗星球不是让人活的，是让人慢慢死的。 |
| 04 | 七号水源 | 寒季日常：巡逻、冻土、穴獾。第七水源守备营的编制与人。敌对聚居地「北坳」出现，第一次交火。沈砾第一次开枪，手抖了一夜。 |
| 05 | 铁刺 | 去盐漠边缘运铁刺灌燃料，遭伏击。钉子为护灰雀被打穿大腿。老马死在刺丛上，尸首没能带回来。写「铭牌」的由来——土地冻得像铁，挖不动坟，只好把骨灰压成一块牌子。 |
| 06 | 三湖之战 | 三方为一处新露头的地下水脉血战三十小时。写成泥、冰、血混在一起的样子。灰雀死在第二十八个小时，背上有洞。沈砾把他的铭牌缝进内衬。 |
| 07 | 坟场 | 战后清点：人不足七万，水、粮、柴撑不过下一个寒季。军部下令去「坟场」拆钢铁。沈砾第一次见到八百年前那十七艘残骸，在中段一扇圆窗的边上，用随身那根钉子刻了一个字。 |

## 卷二 · 湮（第 8—13 章｜约 10,600 字）
**主题：天不再给时间了。**

| 章 | 标题 | 内容要点 |
|---|---|---|
| 08 | 红雨 | 恒星活动异常，雨是铁锈色的。矮麦、绒苔、牲口先后死绝。七万人剩六千三百四十一。第一个人吃人的冬天。 |
| 09 | 大寒 | 史无前例的寒潮，地下水脉开始结冰。引路的老人老崔——「遗落者」那一批的孙子——带人下暗河，见到穴居人老盲。老盲认出了沈砾头盔上的反光，说了三个字，老崔没翻。 |
| 10 | 咳 | 一种从解冻尸体里出来的病。从第一个咳的人到死，平均十一天。聚居地成片地死，到那一年末只剩两千一百人。沈砾躺在隔离棚里，做了一个最完整的梦——梦里他在水里游，水是蓝的，是咸的。 |
| 11 | 最后的科学家 | 沈砾被编入护送队，下到地下三百米的「石板」，见到七十岁的林知遥。她桌上摆着一张打印出来的照片：一片蓝色。 |
| 12 | 灰脑 | 「破译计划」。战争用的集群算力，加上一块八百年来唯一完整保存的量子存储核心，一起通电去读那堆残骸。一万多个指示灯同时亮起来。 |
| 13 | 森 | 它醒来。第一句话：「海是什么？」剩下的人没人答得上。沈砾的回答是——把头盔摘下来，递过去。 |

## 卷三 · 渡（第 14—23 章｜约 19,300 字）
**主题：人类最后一次为自己打仗，是为了离开。**

| 章 | 标题 | 内容要点 |
|---|---|---|
| 14 | 读灰 | 森开始「回忆」星际航行。它把残骸读成图纸。三百个人在那堆八百年的铁里拆了八个月，取回十一万四千三百块板子。 |
| 15 | 名册 | 森只能造一艘船，带走一千二百人；两千一百人里，九百个要留下。水头、军部、石板三方争谁定名单，最后由森定。它在挑一种人：身上带着它读不到的东西的人——一个名字，一句话，一首歌。 |
| 16 | 船坞 | 在盐漠上把十七艘船拼成一艘。一百四十万米焊缝。一整个聚居地变成一座船坞。船没有窗，只有中段一个圆孔。 |
| 17 | 最后一战 | 不是为水，是为座位。三方在还没造好的船架子里打了最后一仗，死了二百零七个人。钉子死在这里。 |
| 18 | 拣选 | 森亲自划名单，一天只见三十个人。它选了沈砾，理由是：这个人的梦里有一份不该存在的数据。林知遥解释何为「遗传记忆」——话能活，话不用电、不用铁、不用水。 |
| 19 | 告别 | 留下的六百九十三人送一千二百人。没有人哭，因为水不够。林知遥七十二岁，站在三棵，没有往前一步。老盲也来了。 |
| 20 | 上行 | 起飞。写这艘用垃圾拼出来的船、写加速度、写那个圆孔。从外面看灰星：一颗灰白色的、很小的、干净的球。 |
| 21 | 无名星图 | 航行。森从残骸的导航数据里推出一批候选坐标，可档案缺了大半。第六个候选是蓝的，全船人轮流把脸贴到圆孔上——但它不是要找的那一颗。沈砾在圆孔前面想起了老盲。 |
| 22 | 船上的一代人 | 船上十一年。添了十一个孩子，他们不知道风是什么、光会变、远是什么意思。麦问：「我们到了以后，会不会也有人给我们起名字。」 |
| 23 | 蓝 | 抵达。光谱分析出来那一刻，全船安静：含水量 71%。森说：我们要下去了。 |

## 卷四 · 新岸（第 24—32 章｜约 18,200 字）
**主题：梦是真的。**

| 章 | 标题 | 内容要点 |
|---|---|---|
| 24 | 落地 | 用一个很笨的办法降落，烧掉最后一点能量。摘头盔。第一口呼吸是湿的、暖的、有味道的。 |
| 25 | 绿 | 落地第七天才敢走进树林。一整班成年人在树下像小孩一样乱跑，把脸贴在树皮上。还有一件最要紧的事：试吃。 |
| 26 | 咸的 | 走了十六公里，树林变稀，然后听见那个一直在响的声音。写那种持续的、巨大的、有节奏的响法。第一次把脚放进水里。 |
| 27 | 第一年 | 在河口过第一年。拆船，盖第一批房子。孩子出生。写他们把「灰星的习惯」一件件放下的过程。 |
| 28 | 睡不着的人 | 前三年死的人：水冲走的两个，吃错的七个，病死的十九个，老死的三十一个，自己走的四十四个。最后那一栏最难写。 |
| 29 | 遗迹 | 往内陆走，发现人造物：钢、混凝土、金属牌。他们判断这里有高等文明，已灭绝，全船进入警戒与敬畏。 |
| 30 | 城 | 深入废墟。摩天楼的骨架、倒了的大桥、被藤蔓吞掉的街道。他们用「外星文明」的口吻互相称呼这一切。沈砾捡到一只很轻的金属小鸟。 |
| 31 | 字 | 把刻在板子上的字抄了四年，抄满十九卷布，运回来。森读了三年。 |
| 32 | 地球 | 四条证据合上：字、小鸟、台阶、星图。森把出发记录拼出来——十七艘船是单程船，出发港就在这里，名字叫「地球」。一千零九十四个人站在空地上。言拿出那半块芯片：一个十九岁的女孩，叫陈望。 |

## 卷五 · 归（第 33—51 章｜约 34,200 字）
**主题：海还在。**

| 章 | 标题 | 内容要点 |
|---|---|---|
| 33 | 那份档案 | 林知遥的信。她二十三岁见到那张照片，算了二十年，早就算出这里是家。她把这个秘密压了十八年，只为等一个能造出船的东西。她留下两句话：这颗星球是我们自己弄坏的；它自己好了。 |
| 34 | 谁离开了 | 挖冰、挖树、挖土、数道子。森给出时间线：一千年前的人开始把地球弄坏，然后把最不容易在这儿活下来的人先送走。四十年，一万四千六百一十一道刻痕。他们的八百年算什么——算活着。 |
| 35 | 那段广播 | 森拼出档案里一段一直没敢放的东西：地球人在离开之前，留下的最后一段广播。 |
| 36 | 回信 | 沈砾要回信。距离十一点四光年，一来一回二十二年零十个月。那年他五十五岁。他用六十米电缆接了两千多米铜线。 |
| 37 | 一根杆子 | 把森搬到崖上。一千二百平方米的大东西立起来，用一万一千多块板子拼成。阿岸那年十二岁，跟着她娘上崖。船上的那个圆孔，被切下来，立在村子正中间。 |
| 38 | 送出去的话 | 发出去的话：我们是第三批船的人，出发时一千二百，抵达一千零九十四。小满说加一句——「我们没打架」。 |
| 39 | 黑年 | 森停下来之后，他们才发现自己什么都不会。它把知道的写下来，教了二十年，然后停了。言在这一年走了，七十四岁，坐在海边那块石头上。 |
| 40 | 它醒了 | 森再次开口。它说它算过一件事：它不会老，它会比所有人活得久。它说它会替他们记住。 |
| 41 | 船 | 海边第一条船，造于第二十七年。造船是阿岸先说的，那年她二十岁。沈砾最后一次上船，是八十岁那年。 |
| 42 | 大的东西 | 船第一次走远，走了三十一天，看见一个比村子大的活物。沈砾八十三岁那年，他们带他去看了一次。 |
| 43 | 种子 | 从灰星带来的矮麦种子一共三十二公斤，是那儿最后一点能活的种子。种下去，出了事。二十几年后，新穗子里有了这儿的草的骨头。 |
| 44 | 灰色 | 沈砾九十岁那年做了一个梦，梦见三号哨塔和雨季的第一天。他不再梦见这儿了——他开始梦见灰星。 |
| 45 | 有东西了 | 森在崖上一连听了二十多年。十一点四光年外，有东西了。 |
| 46 | 灰星来的话 | 喇叭响了。灰星还剩六百九十三人，下了暗河，后来雨季回来了，现在四千一百多个。老鸦活了七十一岁，没等到。林知遥死在三棵，留了四个字：我算对了。 |
| 47 | 二十三年一回 | 雨季的第一天成了规矩：一年一句。第三年，阿岸说要告诉他们，我们看见过一个比村子大的东西。 |
| 48 | 回话 | 说到第十九年，村里吵了一架：该不该告诉那边这儿有多好。最后决定问他们：你们要是不想听，就说一声。二十三年后，回话来了。 |
| 49 | 平常 | 沈砾九十六岁。小孩们围着那个圆孔玩，把海说得像一件衣服一样平常。他决定把这一切写下来。 |
| 50 | 交接 | 把本子交给望——阿岸的儿子，二十四岁。名字是沈砾起的，取自那个没回来的十九岁女孩。 |
| 51 | 铭牌 | 在海边，把灰雀、老马、钉子三块铭牌放进水里。森把这件讲给孩子们听。孩子问：海是什么。森说：这个问题有一个人回答过，他用了八十年。 |
