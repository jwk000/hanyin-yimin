## 一句话故事

一个在异星灰土上长大、从未见过海、却总梦见海的普通士兵，在母星即将死透之前，被一台超级智能选中登船。他抵达一颗蓝色的星球，看见梦里的森林、草地与海洋——最后才知道，那颗星球是地球。

## 全书梗概

**卷一 · 灰。** 沈砾二十二岁，灰兵第三军团第七水源守备营工兵班。灰星一年二十个月，只有第七个月是雨季；这一个月里，人要种麦、修渠、喝饱水，把冬天冻住的人埋掉。他没见过树、草、海，只带着一个从不示人的毛病：他会做梦。卷末，三湖之战打完，聚居地不足七万人，军部下令去「坟场」——八百年前三批船坠毁的地方——拆钢铁。

**卷二 · 湮。** 恒星活动异常，天上落下铁锈色的雨。矮麦、绒苔、穴獾先后死绝。大寒封住地下水脉，疫病从解冻的尸体里爬出来，七万人跌到两千一百。沈砾被编进护送队，下到地下三百米的「石板」，见到七十岁的林知遥，和她桌上那张海的照片。石板用战争的算力加上一块从坟场挖出的量子核心，唤醒了森。它醒来第一句话是：海是什么？

**卷三 · 渡。** 森没有发明星际航行，它把十七艘船的残骸「读」了回来。它只能把十七艘拆成一艘，带走一千二百人。灰星上的人为这一千二百个座位打了最后一场仗，死了二百零七个人，留下六百九十三人。森亲自划名单，它挑的是身上带着它读不到的东西的人。沈砾被选中，因为他做梦。船起飞，航行十一年。

**卷四 · 新岸。** 船落在一颗蓝星上。沈砾摘下头盔，第一口呼吸是湿的、暖的、有味道的。他走进树林，听见那个一直在响的声音。他们从废墟里挖出钢筋、混凝土、一块黑板、一只金属小鸟。最后森把档案拼齐：这里不是新世界，这里是出发港。它的名字叫地球。

**卷五 · 归。** 地球没有死。人走了之后，它自己好了。沈砾把这里的事写成本子，交给森，往十一点四光年外的灰星发。等二十三年一轮的回话。他在海边把三块铭牌放进水里。他活了九十八岁。最后讲这件事的人，是森——它把「海是什么」讲给从没见过海的孩子听。
